## The fyl CLI

The native binaries in `dist/cli/<version>/` (and on the GitHub releases) are built from `cli-rs/` and link these
crates statically, at the versions pinned in `cli-rs/Cargo.lock`. The binaries also contain the Rust standard library
(MIT OR Apache-2.0) and, on Linux, the musl C library (MIT). No crate is under a copyleft license. The full license
texts of all of them are in [`cli-rs/THIRD-PARTY-LICENSES.txt`](cli-rs/THIRD-PARTY-LICENSES.txt), written by
`scripts/cli_licenses.py` and attached to every GitHub release next to the binaries.
Build-time-only crates (`cc`, `proc-macro2`, `quote`, `syn`, `curve25519-dalek-derive` and the like) and the
dev-dependencies are not part of the binaries and are not listed.

## Not distributed

The npm dev dependencies (Biome, esbuild, TypeScript, Vitest, wrangler and the Cloudflare Vitest pool) only build and
test the project; nothing of them is served. esbuild's output for the minified files is fyl's own code with whitespace
and comments removed.
